## Agent Suivi (Sam), première version
- À J+1, J+3 et J+7 : message à la personne dans la messagerie (« Comment se passe ta première journée ? »), réponse enregistrée.
- Relance du parrain si aucun échange n'est visible.
- Page wiki « Suivi de [prénom] » : ce qui est fait, ce qui bloque, résumé pour le manager.
- Même mécanique que les trois agents existants : consigne, vérification dans la base, validation humaine avant toute action sensible. Environ une demi-journée de travail, à tester avant d'être annoncé.

## Idées « waouh », par effet attendu
1. **Vue du nouvel arrivant** : une page « Ton premier jour » (checklist, parrain, plan, un message de Ghost) que reçoit la personne qui arrive. Effet fort en démo : on voit l'onboarding du point de vue de Karim.
2. **Apprendre d'une démonstration** : Sophie prépare une arrivée, Ghost enregistre les gestes et les rejoue pour la suivante. C'est la vraie promesse « répète une tâche » ; aujourd'hui l'onboarding de Léa est un modèle fixe.
3. **Connecteurs réels** : Slack et Teams, Notion, Gmail, Google Agenda, en API quand elle existe, par agent H sinon. Le pitch « hybride » (API ouverte : automatisation ; sans API : agents H) est déjà dans le cadrage.
4. **Invitation de calendrier et e-mail de bienvenue** envoyés réellement (avec validation humaine).
5. **Tableau de bord de l'équipe RH** : temps libéré mesuré sur de nombreux onboardings (aujourd'hui une seule mesure de durée côté agent, la durée humaine reste une hypothèse).
6. **Miroir pour les départs** : même agents, checklist inversée (retrait des accès, restitution du matériel).
7. **Voix plus naturelle** : voix de synthèse payante à la place de celle du navigateur (coût et clé à prévoir).
